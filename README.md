An official **Antigravity IDE plugin** encoding Sagnik Sen's editorial-scientific web theme, standardized GitHub repository layout, topic taxonomy, and CI/CD conventions.

## Included Customizations

- **`skills/sagnik-repo-standards/SKILL.md`** — Standardized README badges, topic taxonomy, MIT license, and GitHub Actions CI templates.
- **`skills/sagnik-web-theme/SKILL.md`** — Editorial-scientific CSS design tokens (`#f6f9fd`, `#275cce`, `#192a43`, `Newsreader`, `IBM Plex Sans`) and GitHub Pages checklist.
- **`rules/AGENTS.md`** — Workspace-wide quality, security, and branding rules.

## Installation

Clone this repository into your Antigravity plugins directory:

```bash
git clone https://github.com/sagnik10/sagnik-sen-antigravity-plugin.git ~/.gemini/config/plugins/sagnik-sen-plugin
```
